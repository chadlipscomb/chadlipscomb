### About

I build things that make the house, the desk and the notes app a little smarter:
microcontrollers talking to Home Assistant, a self-hosted homelab, and small tools
that remove friction from my day.

### Featured

| Project | What it is |
| --- | --- |
| **[pocket-tank](https://github.com/chadlipscomb/pocket-tank)** | A 14M-parameter LLM keeps a virtual fish tank alive on an $8 ESP32-S3, distilled from a 26B teacher into 7.56 MB. No network. |
| **[bleewerlite-esphome](https://github.com/chadlipscomb/bleewerlite-esphome)** | ESPHome external component that drives Neewer LED lights over BLE as native light entities. |
| **[ha-area-averages](https://github.com/chadlipscomb/ha-area-averages)** | Per-area sensor averages for Home Assistant, with offline, stale and low-battery reporting. |
| **[raycast-restart-process](https://github.com/chadlipscomb/raycast-restart-process)** | Raycast extension: fuzzy-find a running process, force-kill it and start it again. |
| **[universal-rack-shelf](https://github.com/chadlipscomb/universal-rack-shelf)** | Parametric OpenSCAD rack-shelf builder. |
